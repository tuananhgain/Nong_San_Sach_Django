# Nông Sản Sạch Django

## 🚀 Giới thiệu
Dự án Django này thực hiện chức năng: user: mua hàng, xem chi tiết, giỏ hàng,thanh toán. admin: quản lý user, khuyến mãi, hóa đơn

## ⚙️ Cài đặt
1️⃣ Clone project:

https://github.com/tuananhgain/Nong_San_Sach_Django.git

2️⃣ Tạo môi trường và cài thư viện:
py -m venv venv
venv\Scripts\activate
pip install -r requirements.txt

3️⃣ Chạy dự án:
py manage.py migrate
py manage.py runserver
